# Remote agent preview

<!-- impeccable:product-schema 1 -->

## Platform

Native macOS (SwiftUI inside an AppKit window); desktop only.

## Users and purpose

The owner of What's up my neighbor wants to hand work to a remote Linux agent while keeping the Mac usable. This first stage verifies a standalone task panel, lifecycle and SSH boundary. The preceding planning conversation and explicit implementation request settle these requirements.

## Capabilities and constraints

Text input, provider selection, fixed local demonstration, progress, result and cancellation. All three providers remain unverified. No live SSH connection without a user-supplied destination. No microphone, cloud calls, browser control, email access or Notes writes in this stage. Persist only the selected provider in a preview-specific directory.

## Brand commitments

Preserve the existing approved black cat, native controls and Traditional Chinese wording. Existing production dictation, clipboard, iPhone relay and cat behavior remain untouched.

## Success

The owner can recognize a demonstration immediately, run and cancel it, read its result and distinguish it from remote execution. Build and test the production app separately; do not install or publish.
