# 教室／Windows 實機驗收

以下是需要人在 Windows 桌面實際操作的清單，不能由編譯或 CI 綠燈替代。請記錄 Windows 版本、測試 App、網路模式與結果，不記錄 API Key 或 token。

## 一鍵安裝與建房（先測這個）

1. 兩台 Windows 10/11 x64，以一般使用者雙擊同一個 `NekoChat-Setup-win-x64.exe`，按安裝並啟動。不得要求安裝 Python/.NET/Git、開終端機或編輯設定。既有 Groq Key／個人設定保留。
2. A 點建立房間、複製邀請碼私下給 B；B 貼上加入。收件人自動設定，兩台互傳中文與 emoji，對方貓咪顯示氣泡並可點擊回覆。
3. 錯誤／截斷／非私有網路邀請碼需拒絕，不得改為公開 WS 或自動降級。用另一個房間的邀請碼不能誤連到舊房間；重複使用同客人身分同時連線要拒絕。
4. A 離開房間／退出／被結束處理程序後，房間服務應停止，B 斷線，舊邀請不可再加入。新建房間取得新帳號／憑證。B 離開不應影響 A 的本機語音。
5. 重複建立／離開至少三次，不能殘留服務程序或有效房間。取消啟動／加入需回到可再次操作的狀態。
6. 用未安裝 Python/.NET SDK 的 Windows 機器測試完整安裝、建房、加入與訊息；防火牆／AP 隔離結果需另外記錄，不得以本機 loopback CI 替代。
7. 更新時舊版仍在執行需提示先離開；不殺程式、不覆寫其他資料夾。個人設定與金鑰保留，舊程式備份可回復。

## LAN 兩台電腦（管理者手動模式）

1. 在一台教室主機依 `../relay/README.md` 建立 alice、bob；各自的個人憑證只交給本人。先不設定好友，啟動 Relay。
2. 兩台 Windows Lite 分別輸入 alice／bob；LAN 位址指向主機私有 IP。同時顯示已連線。alice 傳訊 bob 應收到「尚未取得雙向好友授權」，bob 沒有氣泡。只加一方向也應禁止。
3. 設定雙向好友並重啟 Relay。舊連線必須斷線；兩位重新連線後互傳中文、emoji、換行與接近 2000 字訊息；頭頂氣泡不搶目前輸入框焦點，點擊後回覆收件人是原發送者，完整文字在聊天紀錄可讀。
4. 拖曳貓咪至螢幕邊緣；透明、置頂、右鍵選單、九種花色、匯入現有外觀 JSON／PNG正常；多螢幕、不同 DPI、睡眠／鎖定恢復後仍能操作。
5. bob 中斷後 alice 發送應顯示離線且草稿保留。恢復 bob，alice 明確重新傳送；「已送達」後才清草稿。中途切網路會顯示斷線，不能顯示成功或自動重送。
6. 錯 token、他人 ID 搭配自己的 token、同帳號第二連線均拒絕。撤銷 alice、重啟 Relay 後 alice 不能重連，bob 仍可驗證。
7. 從同網路嘗試連線主機 TCP 8765；不通時先排查主機 IP、私人網路入站授權與 AP／VLAN 隔離。學校不允許互連時使用管理者已部署的 VPS WSS，保留 LAN 測試未通過的紀錄。

## 語音輸入與聊天

1. 每人僅在 App 設定自己的 Groq Key。重開 App 後無須重填；Windows 認證管理員可見專用 Generic Credential，settings.json、repo 與程式日誌不可含 Key／token。
2. Windows 記事本放游標於句中，Ctrl+Alt+Space 開始、說話、再按停止：只插入文字，不送出 Enter，貓咪狀態不搶焦點。
3. 在另一個已授權的文字 App 重複測試（例如瀏覽器 textarea）。錄音後切到其他視窗、不同文字框、密碼欄、唯讀欄位或提升權限的 App：不得輸入到錯誤目標；應複製或保留最近轉錄，並顯示原因。UIA 不支援時複製是預期結果。
4. 長按快捷鍵只啟動一次；Esc／取消按鈕可取消；錄音 60 秒自動停止。拒絕麥克風、拔除麥克風、網路中斷、Groq 無效 Key／額度限制：顯示可理解的失敗，不送出空訊息或私密錯誤內容。取消後不應出現文字輸入或傳訊。
5. 聊天語音辨識後先成草稿；可修改、確認好友，再按傳送。錄音中收到好友文字只顯示氣泡，不啟動任何錄音、輸入或命令。兩種錄音同時啟動必須被阻止。
6. 關閉視窗只收起聊天；離開 App 才停止。退出後無錄音、熱鍵占用或自動重連。使用設定中的刪除按鈕確認 Groq／Relay 憑證可移除。

## VPS

LAN 與 VPS 各有獨立位址、憑證；切 VPS 後只能接受 WSS 與有效 TLS。明文公共 WS、自簽無效憑證、Office/VNC端點均不能連。VPS 雙向好友、撤銷／重啟、斷線結果應與 LAN 一致；不可因失敗自動退回明文連線。
