# 貓咪辦公室第一版

基準：`cb60121c6319ee6806f650b6438c0ea663c77bef`，分支 `codex/neighbor-office-v1`。
使用者於 2026-10-21 授權確認真實 VPS、選小模型，部署自然語言交辦、持久進度與成果第一版。

## 影響與邊界

- 新增獨立 `office/` Python 標準庫服務、網頁及測試；不改 Mac 正式 App、原遠端預覽、SSH/VNC 或未提交的 phase2 草稿。
- 讀取來源為本服務 `inbox/` 的文字檔，成果寫入獨立 UUID 任務目錄；SQLite 記錄任務、階段與事件。
- 模型只提出有限動作；程式驗證後讀檔與存檔，不執行模型產生的 shell 或任意路徑。
- 私人 loopback HTTP 由 SSH 保護。寫入需同源檢查及隨機 token；介面使用 textContent 顯示使用者與模型內容。
- 第一期不接外部帳號，研究或大模型工作保存為待串接任務，不能回報為已完成。
- 風險中等：VPS 新增使用者層服務與本機推論；不需 sudo、不開新公網埠。模型品質與兩核速度須真機量測。

## 實作順序

1. 真機規格、服務與既有 repo 基準：已確認；既有 AgentCore 16 scenarios 通過。
2. 使用者層安裝固定版本 Ollama，測 Gemma 3 1B 的繁中結構化派工與短摘要；不足時比較 4B。
3. 實作持久任務、受限文件工具、模型適配器與可取消背景 worker。
4. 提供瀏覽器房間入口：自然語言、文字上傳、任務事件、成果；SSH 斷線不停止工作。
5. 離線驗證取消／重啟恢復／重複送出／檔案與 HTTP 邊界；真 VPS 用真模型驗證成果並獨立讀回。
6. VPS 使用者層服務部署、SSH 入口驗證、開啟實際頁面；交付路徑、操作方式、量測與限制。
