# VPS 工作交接與生活紀錄第二版

使用者於 2026-10-21 授權：Gemma 改選配，保留任務／進度／成果，接通一個外部 Agent，接進貓咪面板。基準為 cb60121 與 office-v1 未提交原始碼；前版原始碼複本留在 build/office-v2-baseline，真 VPS 資料先備份。

## 影響與決策

- office/ 新增 Codex CLI 適配器、每任務 executor、交接與生活紀錄，舊任務仍指向 Gemma；既有結果與來源快照保持。
- 預設新任務走 Codex；Gemma 僅明確選取時啟動，不依賴常駐 Ollama。Codex 需使用者在 VPS 本人登入，不搬 Mac 憑證、不另開 API 付費帳號。
- 外部 Agent 僅取得本次交辦、選定來源及明確選取的交接／生活紀錄。生活原文預設只保存 VPS，不自動外送。
- 工作交接包括原任務、成果、手動補充與下一步；接續工作建立子任務，不重跑或覆寫舊任務。
- 持久記憶為產品自己的 SQLite + Markdown，不是 Codex 全域記憶，不導入 Hermes 套件。
- Mac 獨立預覽新增辦公室分頁，以既有嚴格 SSH 通道連線；HTTP health 確認後載入私人頁面。保留示範與 VNC 功能。正式 App 與已安裝預覽不覆寫；新預覽用獨立識別與建置路徑。
- 風險：中高，因新增外部處理及資料表。藉資料庫備份、可重複 migration、選取式上下文、有限工具、原始內容落盤與取消程序群組約束。

## 順序與驗收

1. 前版 24 項測試及 AgentCore 基準；備份 VPS SQLite、app 與服務設定。
2. 安裝並核對官方 Codex CLI 發行檔，完成只讀登入狀態查詢；登入由使用者本人完成。
3. 加法式資料表遷移、交接與生活紀錄端點／匯出；測舊紀錄保持、冪等、重啟與選取式上下文。
4. Codex 執行器：stdin、JSONL 進度、限定工作目錄、停用 shell 工具、read-only sandbox、有限時間與程序群組取消；真實登入後驗證合成資料任務與來源。
5. 私人辦公室頁面新增執行者、交接與生活紀錄；native 貓咪預覽連線並讀回同一份 VPS 資料。
6. 關閉預設 Ollama，在無本機模型情況下實測記錄、交接、Codex 任務及重啟。另驗證明確選 Gemma 的路徑。
7. 交付實測結果、登入／原生預覽狀態與尚未驗收項目，不將假 CLI 成功當成外部服務成功。
