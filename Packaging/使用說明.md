# What's up my neighbor

安裝後選單列會出現小黑貓圖示，所有設定都從這裡進入。App 檔案名稱是 `AI語音輸入.app`（舊名稱），開啟後顯示為 What's up my neighbor。

## 安裝

1. 對 `安裝.command` 按右鍵，選「打開」。
2. 若 macOS 阻擋，前往「系統設定 → 隱私權與安全性」並選「仍要打開」。
3. 依首次啟動畫面按「開啟 Groq API Keys 網頁」，建立自己的 Key。
4. 貼上以 `gsk_` 開頭的 Key，按「安全儲存」。
5. 允許麥克風與輔助使用權限。

已經裝過的話，安裝工具會沿用原本的位置（不一定在「應用程式」資料夾），保留 API Key 與設定，並在終端機視窗顯示實際安裝位置與安裝類型（全新安裝、更新或重新安裝同一版）。舊版會留在安裝位置旁的隱藏資料夾 `.neighbor-update.*`，確認新版正常後可以丟到垃圾桶。

## 使用

- 預設按 `Option + ↑` 開始錄音，再按一次停止。
- 點選單列小黑貓圖示 →「設定快捷鍵…」，可改成自己的組合。
- Mac 本機快捷鍵只會貼上文字，不會替你按 Enter。
- 若沒有輔助使用權限，文字仍會留在剪貼簿，可手動貼上。

## 剪貼簿歷史

- 錄音結束照常貼上；語音結果與一般複製文字共用最近 10 筆紀錄。
- 一般短按 `⌘V`，放開 V 時貼上目前內容。要選歷史，按住 `⌘V` 再按 `↑`／`↓`，清單會從上一筆開始選；不會先貼入最新一筆。
- 清單打開後，可以放開 Command／V，再用上下方向鍵選擇。單純放開按鍵不會貼上或關閉清單。
- 也可按 `⌃⌥V` 或點小黑貓選單的「剪貼簿歷史」；既有自訂快捷鍵會保留。Command＋V 手勢需要輔助使用權限，無法啟用時仍可使用這兩個入口。
- 點選一筆，或用上下方向鍵選擇後按 Enter 貼回原本輸入框。Enter 只確認選取，不會送出訊息；Esc 關閉。
- 若輸入位置無法確認，文字仍留在剪貼簿，回到需要的位置按 `⌘V` 即可。
- 相同文字合併，選回的文字移到最上方；超過 10 筆移除最舊內容。
- 紀錄只保存在本機，重開 App 後仍保留，不建立錄音檔歷史。「剪貼簿設定」可暫停或清除紀錄，暫停時仍能正常語音輸入。

## 桌面貓咪毛色

點選單列小黑貓 →「選擇貓咪花色」，可直接選原版黑貓、黑貓、白貓、灰貓、橘虎斑、賓士貓、三花貓、玳瑁貓與重點色貓。選好後桌面貓立即換色，若原本收起則直接放出；不需要重開 App，也不需要編輯設定檔。預設原版黑貓，App 會記住最後選擇。

錄音浮窗與問候也會套用新毛色；有指定自訂 PNG 時，這兩個畫面仍使用你的圖片。正在錄音或辨識時，先完成後再切換。手動設定的自訂部位與花紋會保留，選單不會直接覆蓋。

QA 安裝包的選單會另外顯示「QA 測試版」與來源編號；正式發布前，版本數字可能仍與 1.4.5 相同，請以 QA 標記確認正在測試的版本。

## 客製貓咪包

包含角色包功能的版本可從「自訂貓咪…」設定左右眼顏色、鼻子特徵、項圈與蝴蝶結，按「儲存並套用」即可保存。已保存角色列在「我的貓咪」；「匯入貓咪包…」與「匯出目前貓咪…」可交換 `.nekocat`。收到別人的貓咪包時，也可雙擊檔案交給 App 讀取；成功匯入後會保存在本機，原下載檔可自行移動。

如果這份交付包附有 `FirstCat.nekocatsetup`，`安裝.command` 會先保存一份待匯入副本，再交給 App；首次使用可自動套用這隻貓。已經選過外觀或有自訂設定時會保留原本選擇，想明確改用新貓，可雙擊同資料夾的 `我的貓.nekocat`。操作不會更動你的 API Key、快捷鍵、問候文字或其他偏好。

尚未啟動或暫時開啟失敗的 App 會在下次啟動處理待匯入文件。格式不相容或無法讀取時，App 會保留目前可用的外觀。詳細格式與客製範圍見交付資料夾內的 [docs/CAT-PACKS.md](docs/CAT-PACKS.md)；正式版 1.4.5 不支援此功能。

## 更新

App 每日偵測新版，通知後由你自行選擇是否下載安裝；也能從選單點「檢查更新…」，或關閉「自動偵測新版本」。第一次有新版時會詢問通知權限；拒絕也可使用 App 內提示。

更新保留 API Key、快捷鍵及使用者資料夾的 `cat.config.json` 與圖片，不要先執行移除程式。錄音或辨識期間會延後提示與重新啟動。舊版仍需要手動安裝一次含更新器的版本；免費版沿用固定簽章與原安裝位置；第一次開啟可能有 macOS 安全確認。若舊版身分不同，macOS 仍可能要求重新授權麥克風／輔助使用或 Keychain。

## 文字輸出模式

點選單列小黑貓圖示 →「文字輸出模式」可以切換：

- **純逐字（預設）**：講什麼就留什麼，只修簡繁、標點與中英文空格。適合逐字紀錄、會議、法律內容。
- **標準**：另外移除句首的「呃、嗯」和明顯重複的詞。
- **簡潔**：再移除句尾語氣詞（啊、啦、喔）。適合傳訊息，但語氣會變得比較直接。

例如「嗯，好啊，那個報告我明天再給你喔」：純逐字完全不動；標準變成「好啊，那個報告我明天再給你喔」；簡潔變成「好，那個報告我明天再給你」。

三種模式都不會摘要、不會改寫成 Email、不會自動條列，也不會重組句子。法律用語不會被改寫。

## 語言設定

點選單列小黑貓圖示 →「語言設定…」，最多可以設定三種語言：一個主要語言，加上最多兩個允許混用的語言。預設是繁體中文加英文。

主要語言也會決定辨識時使用的語言，所以改成日文之後就不會再做簡繁轉換。

## 文字與錄音設定

點選單列小黑貓圖示 →「文字與錄音設定…」：

- **中文數字轉阿拉伯數字**（預設關閉）：「第一百五十九條」變成「第159條」。只轉法條、金額與百分比，成語不會被動到。
- **第二快捷鍵**：設定後可以一鍵用另一種模式錄音，只影響那一次。
- **靜音自動停止**（預設關閉）：講完停頓幾秒後自動結束錄音。
- 錄音最長 5 分鐘，這個保護一律啟用。

## 辨識失敗時

- 錄音在文字成功放進剪貼簿前不會刪除，網路中斷或辨識失敗時會問你要不要「重新辨識」，不用重講。
- 如果辨識出大量非中英文的內容（例如沒出聲時的誤判），App 不會直接貼出來，會自動用中文重試一次。
- 暫留的錄音兩分鐘後自動刪除，關閉 App 也會刪除。

## iPhone 遠端（選用）

1. 確認兩台裝置的 Wi-Fi、藍牙都已開啟，iPhone 也已允許「Groq 語音輸入」使用區域網路。
2. 點選單列小黑貓圖示 →「配對 iPhone…」，保持視窗開啟。
3. 在 iPhone App 的「Mac 連線」輸入六位數配對碼，再點找到的 Mac。
4. 配對碼五分鐘後失效，且成功使用後不能重用；失敗時請由 Mac 重新產生新碼。
5. 日常使用時先讓 Mac 游標停在聊天輸入框，再從 iPhone 開始錄音。
6. 在 iPhone 修正辨識文字後，選「只貼上」或「貼到 Mac 並送出」。

只有 iPhone 上明確按下「貼到 Mac 並送出」時，Mac 才會在確認輸入框未改變後模擬 Enter。

若 iPhone 找不到 Mac，先確認 Mac 選單列 App 正在執行並等待 5–10 秒。若曾拒絕權限，前往 iPhone `設定 → 隱私權與安全性 → 區域網路` 開啟「Groq 語音輸入」。仍無法重連時，讓兩端忘記舊配對，再使用新的六位數配對碼。

## Groq API Key

- 每位使用者必須使用自己的 Groq API Key。
- Key 只會存進 macOS 鑰匙圈。
- 從選單列選「設定／更換 Groq API 金鑰…」可隨時更新。

## 移除

執行 `移除.command`，會一併刪除 App、登入啟動設定、偏好設定（含快捷鍵與本機詞典）及 Keychain 中的 Groq API Key。App 不論裝在 `~/Applications`、`~/Library/Application Support/AI語音輸入/` 或 `/Applications`，都會先確認是這個 App 才刪除。

不會刪除剪貼簿歷史（`~/Library/Application Support/AI語音輸入/ClipboardHistory/`）、貓咪設定（`~/Library/Application Support/tw.panh.FreeVoiceType/`，也就是小黑貓選單「開啟貓咪設定資料夾…」打開的那個資料夾）與安裝時留下的舊版備份（App 所在資料夾裡以 `.neighbor-update.` 開頭的資料夾）；終端機視窗會列出它們的位置。想完全清除，請在 Finder 用「前往」→「前往資料夾…」打開後手動丟到垃圾桶。舊版備份的名稱以點開頭，Finder 預設隱藏，按 `Command + Shift + .` 可以顯示。
